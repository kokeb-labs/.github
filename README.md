# kokeb-labs/.github

The organization's front door and rulebook.

| Path | What it is |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The page shown at <https://github.com/kokeb-labs> |
| [`standards/`](standards/README.md) | The Kokeb Labs engineering standard: layers, drivers, errors, threading, naming, docs, releases, governance |
| [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md), [`GOVERNANCE.md`](GOVERNANCE.md) | Community files. GitHub shows them in every repository that has none of its own |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE), [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default issue forms and PR template for every repository |
| [`org/`](org/README.md) | Repository settings, security, rulesets and labels as code, with a script that applies them |
| [`brand/`](brand/README.md) | The logo, its generator and the colour tokens |
| [`TRADEMARKS.md`](TRADEMARKS.md) | How the name and logo may be used |

Changes go through a pull request like any other repository. A change to a rule in `standards/` comes with an ADR.
