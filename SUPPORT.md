# Getting help

| You want to | Go to |
| --- | --- |
| Ask how to use a driver or kb-core, or discuss an idea | [Discussions](https://github.com/orgs/kokeb-labs/discussions) |
| Report a bug you can reproduce | An issue in the affected repository, using the bug form |
| Ask for a new chip driver | The **Driver request** form in any repository |
| Report a vulnerability | Privately, as [SECURITY.md](SECURITY.md) describes |

Before asking, check the repository's documentation site (linked from its README) and its troubleshooting page.
Include the repository's tag or commit, your MCU and RTOS, and the smallest code that shows the problem.

Kokeb Labs is maintained by a small team. Answers in Discussions come on a best-effort basis; there is no paid
support channel yet.
